# ⚡ Optimal Placement of Electric Vehicle Charging Using Machine Learning

This project aims to identify optimal locations for installing EV (Electric Vehicle) charging stations using machine learning models. By analyzing vehicle density, existing infrastructure, and geographical distribution, we provide data-driven insights to support smart city planning and sustainable transportation growth.

---

## 🧠 Objective

- Predict areas lacking sufficient EV charging infrastructure
- Cluster regions based on EV adoption and travel patterns
- Visualize underserved zones and recommend installation points

---

## 📂 Dataset

- **EV Registration Data**: Includes vehicle type, location (city/state/zip)
- **Charging Station Data**: Existing stations with coordinates
- **Geospatial Info**: Latitude, longitude, and demographic patterns
- **Sources**: https://catalog.data.gov/dataset/electric-vehicle-population-data
  
---

## 🛠️ Techniques Used

- **Data Cleaning & Preprocessing**
- **Exploratory Data Analysis (EDA)**
- **Clustering** (KMeans)
- **Predictive Modeling** (Linear Regression, Random Forest)
- **Geospatial Mapping** using `folium`, `plotly`, or `geopandas`

---

## 🔧 Tools & Libraries

- Python (Pandas, NumPy, Scikit-learn, Matplotlib)
- Google Colab
- Geopandas, Plotly, Folium
- Git, GitHub

---

## 📊 Output

- Visual heatmaps of high-demand regions
- Clustered zones needing infrastructure
- Predicted demand vs existing coverage
